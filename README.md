## How to reproduce

**1. Install dependencies** (Python 3.11):

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. Download the competition data** into a `data/` folder in the repository root
(the data are not included in this repository, as redistribution is not permitted):

```bash
kaggle competitions download -c bt-4012-competition-2026 -p data
unzip data/bt-4012-competition-2026.zip -d data
```

Expected files: `data/train.csv`, `data/test.csv`, `data/txs_edgelist.csv`, `data/sample_submission.csv`.

**3. Run the notebook:** open `e1155503.ipynb` and select **Restart & Run All**.
Runtime is roughly 15–25 minutes on a laptop CPU, mostly in the validation section (Section 6), which can be skipped
to go straight to the final model (Section 7).

**Output** (written to `submissions/`):
- `final_submission.csv`: top submission (graph features + SMOTE)
- `final_submission_no_smote.csv`: second selected submission

All random seeds are fixed, so results are reproducible.

## Approach (summary)

- **Validation:** three expanding time-window folds (train on past steps, validate ~10 steps ahead), mirroring the
  future test period; label-dependent features are rebuilt inside each fold.
- **Features (259):** 165 raw features + 5 structural graph features + 80 neighbour feature averages + 9 neighbour
  fraud-probability features (two-stage, out-of-fold by time step to prevent label leakage). Neighbour features use only
  transactions with available features, keeping them consistent between training and test periods.
- **Class imbalance:** SMOTE oversampling to a 1:1 ratio, applied to training rows only.
- **Model:** LightGBM, averaged over 5 random seeds.

See the report (`e1155503.pdf`) for details and discussion.
